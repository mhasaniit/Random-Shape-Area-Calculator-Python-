# Geometric Shapes Calculator (Python OOP Project)

## Overview
This project was developed as the final project for ITM 313. It is a Python-based program that works with basic geometric shapes, including circles, squares, and cuboids. The program applies object-oriented programming principles to generate and process shape data dynamically.

## Features
- Random generation of geometric shapes (circle, square, cuboid)
- Calculation of area or surface area depending on shape type
- Multiple output options for results:
  - Display in the terminal
  - Save results to a text file
  - Display results in a simple Tkinter GUI window
- User-friendly interaction for selecting output preferences

## OOP Concepts Applied
- **Classes and Objects** – Each shape is represented as a class
- **Encapsulation** – Shape properties and calculations are contained within classes
- **Inheritance / Shared Methods** – Common structure used across different shapes
- **Polymorphism** – Different shapes implement their own area/surface area calculations

## Technologies Used
- Python
- Tkinter (for GUI)
- File handling (text output)

## System Design
The program generates a random list of shape objects and processes them using shared object-oriented structures. Each shape class defines its own formula for calculating area or surface area, and the system handles output based on user selection.

## Output Options
Users can choose how results are displayed:
1. Terminal output  
2. Saved text file  
3. Tkinter GUI window  

## Purpose
The goal of this project was to strengthen understanding of object-oriented programming in Python, while also introducing basic GUI development and file handling techniques.
